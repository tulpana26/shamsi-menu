Доступ к меню

Панель работает прямо с репозиторием tulpana26/shamsi-menu. Нужен токен GitHub с правом «Contents: Read and write» только на этот репозиторий. Токен хранится в этом браузере и никуда не отправляется, кроме api.github.com.

  1. Откройте создание токена (fine-grained).
  2. Repository access → Only select repositories → shamsi-menu.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Срок действия — на ваш выбор, например 90 дней.
