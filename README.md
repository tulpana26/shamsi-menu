# SHAMSI — web menu

Клиентское меню кофейни SHAMSI: статический сайт без сборки, открывается по ссылке
и по QR-коду со стола. Данные меню лежат в одном файле.

## Как это устроено

```
index.html              — разметка страницы
assets/style.css        — оформление (палитра со стаканов: бордо, крем, золото)
assets/app.js           — рендер меню, поиск, подсветка разделов, QR
assets/menu-data.js     — ЕДИНСТВЕННЫЙ файл с меню (категории, позиции, цены, имена фото)
assets/photos/          — фотографии позиций (800×667, 6:5)
```

Меню рендерится из `menu-data.js`, поэтому правки цен и позиций не требуют
трогать код.

## Как обновить меню

1. Откройте `assets/menu-data.js`.
2. Категория — объект `{ "id": "hot-coffee", "name": "Горячий кофе", "items": [...] }`.
   `id` — латиница, используется в якорях и ссылках.
3. Позиция — `{ "name": "Капучино", "prices": [{ "label": "Б.", "value": 250 }, { "label": "М.", "value": 220 }] }`.
   Одна цена — один объект в `prices` без `label`.
4. Сохраните, закоммитьте, запушьте — сайт обновится через минуту.

```bash
git add assets/menu-data.js
git commit -m "меню: обновили цены"
git push
```

## QR

Кнопка **QR** в шапке рисует код на текущий адрес страницы и умеет печатать
готовую карточку для стола (кнопка «Печать» → Ctrl/Cmd+P). Код строится в браузере,
ничего не хранится на сервере.

## Панель управления (без кода)

Открывается по адресу **/admin/** на том же сайте, например
`https://tulpana26.github.io/shamsi-menu/admin/`.

Что умеет:

• менять название, описание и цены любой позиции, добавлять и удалять позиции;
• заменять фото прямо с планшета, файл не нужно готовить заранее —
  браузер сам обрежет его до 6:5 и сожмёт в JPEG 800×667;
• каждая правка сразу коммитится в репозиторий, сайт обновляется через минуту.

Вход по токену GitHub (fine-grained, право **Contents: Read and write** только на
`shamsi-menu`). Токен хранится в localStorage браузера и уходит только на api.github.com.
Без токена страница ничего не показывает и ничего не может изменить.

Фото лежат в `assets/photos/<slot>.jpg`; имя файла (`slot`) записано в
`assets/menu-data.js` в поле `photo`. Поэтому фото можно менять и вручную в
GitHub: достаточно загрузить новый файл с тем же именем — размер и пропорции
панель приведёт сама при следующей замене, а если грузите руками — держите 800×667.

## Локальный просмотр

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация

Хостинг — GitHub Pages: ветка `main`, папка `/` (корень).
Свой домен подключается в Settings → Pages → Custom domain.

## Android-приложение

Готовый APK: `download/SHAMSI-menu-1.1.apk` (Android 7 и новее), иконка — фирменный логотип.
Исходники и скрипт пересборки: папка `android/`.
Приложение открывает этот же сайт, поэтому смена цен и фото в панели
подхватывается без пересборки APK.

## Источник данных

Меню и фотографии перенесены с публичной страницы menu-touch
(`app.menu-touch.fr/insite.php?id=24167`): 16 разделов, 59 позиций, цены с размерами Б./М.
Фото лежат в `assets/photos/`, приведены к единому размеру 800×667 (родная пропорция 6:5, ничего не обрезано).

Пять позиций (тоники и авторский чай) остались с временными кадрами,
и одна («Омлет-рулет с индейкой») — с плейсхолдером: в menu-touch у них нет фото.
При появлении реальных снимков достаточно заменить файл в `assets/photos/`
или добавить его и прописать имя в `menu-data.js`.
